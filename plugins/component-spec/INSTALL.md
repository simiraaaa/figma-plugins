# Component Spec プラグイン インストール手順

Figma で選択したコンポーネント群から、variant / props の仕様を JSON に書き出すプラグインです。
出力した JSON はそのまま仕様書の元データにしたり、Claude 等の AI に貼り付けて使えます。

## 必要なもの

- **Figma デスクトップアプリ** (ブラウザ版では開発プラグインを読み込めません)
  - 未インストールなら https://www.figma.com/downloads/ から
- 配布された zip ファイル (`component-spec-plugin.zip`)

## インストール (初回のみ)

1. zip を展開し、`component-spec` フォルダを**消さない場所**に置く
   (例: 書類フォルダの中。デスクトップや一時フォルダは避ける。移動・削除するとプラグインが動かなくなります)
2. Figma デスクトップアプリで任意のデザインファイルを開く
3. メニュー → **Plugins** → **Development** → **Import plugin from manifest...**
   (日本語 UI の場合: **プラグイン** → **開発** → **マニフェストからプラグインをインポート...**)
4. 手順 1 で置いたフォルダ内の **manifest.json** を選択

これで完了です。以降はどのファイルでも Plugins メニューから使えます。

## 使い方

1. コンポーネントのパターンが並んでいるフレーム (またはコンポーネントセット) を選択する
2. メニュー → **Plugins** → **Development** → **Component Spec** を実行
   (日本語 UI の場合: **プラグイン** → **開発** → **Component Spec**)
3. 検出されたコンポーネントの一覧がチェックボックス付きで表示される
   - 不要なものはチェックを外す
   - プラグインを開いたまま別のフレームを選択し直すと、一覧も追従します
4. 出力する
   - **JSON をコピー**: 仕様 JSON をクリップボードへ。AI に貼り付ける用
   - **ZIP を DL**: 仕様 JSON + 各パターンのスクリーンショット PNG。仕様書に添付する用

## 更新のしかた

新しい zip を受け取ったら、手順 1 と同じ場所に**フォルダごと上書き**するだけです。
再インポートは不要です (Figma は置いた場所のファイルを毎回読みます)。

## うまく動かないとき

- メニューに Component Spec が出ない → Development (日本語 UI では「開発」) 配下にあります。無ければ再インポート
- 「フレームを選択してください」と出る → 何も選択していない状態です。フレームを選択してから実行
- 一覧に何も出ない → 選択の中にコンポーネント (インスタンス・コンポーネント・コンポーネントセット) が含まれていません
- 画面に警告 (warnings) が出る → 出力は続行されています。壊れたコンポーネントセット等の可能性があるので、内容を開発者に共有してください
